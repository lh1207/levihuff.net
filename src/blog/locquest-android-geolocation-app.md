[LocoQuest](https://github.com/lh1207/LocoQuest) is an academic Android team project for exploring geographic benchmarks using maps and device location. I contributed alongside Derrick Adkins and William Bohman, as listed in the repository README.

## Implementation

The application uses Kotlin and Android APIs. Its [Home.kt source](https://github.com/lh1207/LocoQuest/blob/main/app/src/main/java/com/locoquest/app/Home.kt) includes Google Maps integration and device-location handling.

The repository contains the Android project, settings and profile screens, and benchmark data components. The source is the reference for implemented behavior; the README also contains planned work.

## My involvement

This was shared development work. My commit history includes updates to the settings screen and project documentation. The app belongs in my academic portfolio, rather than as an example of professional mobile application ownership.
