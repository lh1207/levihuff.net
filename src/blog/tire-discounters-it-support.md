My Infrastructure & Cybersecurity co-op at Tire Discounters ran from August to December 2022. The work included on-site and remote user support, support tickets, employee onboarding, and Windows workstation setup.

## Support and onboarding

I worked on support requests and helped document onboarding steps. Account-related work included Active Directory and PowerShell provisioning tasks.

The role combined user communication with technical work: handling a support request, helping a new employee get set up, and keeping the next technician's instructions clear.

## Windows imaging

I assisted with Windows imaging using Microsoft Deployment Toolkit (MDT). Imaging and workstation setup were part of the co-op, alongside the broader support work.

My later [personal Windows and Active Directory lab](/infrastructure/imaging-lab/) is a separate project. Its scripts and configuration records provide examples of lab work, not evidence of an employer's environment.
