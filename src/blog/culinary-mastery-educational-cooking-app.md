I was a member of University of Cincinnati Senior Design Team 7 for Culinary Mastery, a cooking education web application. The [IT Expo 2025 project page](https://itexpo.live/2025/seniors/280/) lists the team, including me.

## Team project

Culinary Mastery combines cooking videos with written learning material. The Expo abstract describes YouTube integration and AI-generated explanations and translations. These are project-level features developed by the team.

## Implementation

The [public repository](https://github.com/24-25-UC-Senior-Design-Group-7/Culinary-Mastery) contains a React web interface and Node.js/Express backend.

- [package.json](https://github.com/24-25-UC-Senior-Design-Group-7/Culinary-Mastery/blob/main/package.json) lists the web application dependencies.
- [server/app.js](https://github.com/24-25-UC-Senior-Design-Group-7/Culinary-Mastery/blob/main/server/app.js) wires the Express routes.
- [server/services/geminiService.js](https://github.com/24-25-UC-Senior-Design-Group-7/Culinary-Mastery/blob/main/server/services/geminiService.js) contains AI service integration.

This was an academic team project. My participation is part of my software development background, alongside the support experience described on my [About page](/about/).
